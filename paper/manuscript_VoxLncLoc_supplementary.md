# VoxLncLoc: ablation grids (Supplementary Tables 1–15)

These tables are reproduced from the source file *3.1 Ablation studies* without changing cell values, column headers, or row order. They support Section 3.1 of the main text. Best scores within each table remain as in the source document (boldface).

**3.1 Ablation studies**

Following CFPLncLoc-style analysis, we first ablate key components on each official benchmark before comparing with literature methods. For every dataset we report three stages with the full metric suite used later for peer comparison: (i) 3D-CGR voxel encoding under RF, ET, LightGBM, XGBoost, and HistGradientBoosting; (ii) exact *k*-mer order *k* ∈ {5, 6, 7, 8}; (iii) concatenation of the training-side voxel setting with the *k*-mer control (kept only as a control, not as a designed second branch). Shared encoding parameters (α, V, σ, arc+idx, PCA) are stated once in each table caption; rows keep only the varying fields (Setting / *S* / *n_pts* / Head, or *k* / Dim / Head, or Head (concat)). Each ablation table uses the corresponding native metric suite (D_LncDNN / D_gShape / D_Yi / D_MGBLncLoc / D_GRASP as defined in Section 2.1) and lists RF/ET/LGBM/XGB/HGB heads. Best primary scores within each table are boldfaced.
